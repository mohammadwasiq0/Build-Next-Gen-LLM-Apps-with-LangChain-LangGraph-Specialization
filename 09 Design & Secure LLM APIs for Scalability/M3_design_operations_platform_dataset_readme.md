# GlobalCorp Metrics and Cost Data

## Overview
This file contains synthetic metrics and cost data for GlobalCorp's LLM API operations platform. The data supports monitoring dashboard creation, performance optimization exercises, and cost analysis.

## Dataset Schema
- `baseline_metrics`: Performance and cost metrics before optimization
- `optimized_metrics`: Expected metrics after applying optimizations
- `monitoring_thresholds`: SLO targets for alerting
- `cost_breakdown`: Monthly cost breakdown by infrastructure component

## Usage Notes
- Use baseline metrics to configure initial monitoring dashboards
- Compare optimized metrics to validate performance improvements
- Apply monitoring thresholds when creating alert rules
- Reference cost breakdown for budget optimization exercises

## Sample Size
This is a reference dataset with representative metrics. Actual metrics will be generated during lab execution based on traffic patterns and infrastructure configuration.

## Key Metrics
- Latency percentiles (p50, p95, p99) for SLO monitoring
- Cache hit rate for performance optimization
- Cost per request for budget management
- Error rate and availability for reliability tracking

## Privacy & Compliance
All metrics are synthetic and do not contain real user data. Use for instructional purposes only.
